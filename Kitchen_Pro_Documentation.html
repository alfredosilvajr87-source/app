Multi-Tenant Architecture / Arquitectura Multi-Tenant Every document in MongoDB includes a company_id field. All queries are scoped to the authenticated user's company, ensuring full data isolation between tenants.
Cada documento no MongoDB inclui um campo company_id. Todas as queries são filtradas pela empresa do utilizador autenticado, garantindo isolamento total entre clientes.

Order Calculation Logic / Lógica de Cálculo de Encomendas

🧮
PAR Level Hierarchy (priority order)
1. item_unit_config.{day}_qty — per-unit, per-day override (highest priority)
2. item_unit_config.minimum_stock — per-unit override
3. item.minimum_stock_by_day.{weekday} — global per-day
4. item.minimum_stock — global fallback (lowest priority)

Formula: order_qty = PAR + safety_stock_increment − latest_stock_count
